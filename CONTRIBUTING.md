# Contributing

Thanks for contributing to Sharp AI.

## Guidelines

- Keep changes focused and explain meaningful behavior changes.
- Do not commit API keys, credentials, `.env` files, or generated artifacts.
- Run the available lint and test commands before submitting a change.
- Update the README when setup, commands, or user-facing behavior changes.

## Pull requests

Describe what changed, how it was tested, and any known limitations.
